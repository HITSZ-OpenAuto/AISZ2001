第二章 回归学习
================================================================================

一、名词解释（7个）
---------------------------------------------------------------------------

1. 回归学习
   有监督学习方法，预测目标是连续数值（房价、销量），不是离散类别。核心思想：
   用历史数据拟合一条最佳预测趋势线，用规律推测未知情况。

2. 线性回归
   假设输出是输入特征的线性加权和：y = w·x + b，w 为权重，b 为偏置。通过最小
   化预测值与真实值的误差来求解最优参数。求解方法：解析解（最小二乘法）w* =
   (X^T·X)^(-1)·X^T·y；迭代解（梯度下降）。

3. 梯度下降
   迭代优化算法，用于寻找代价函数最小值。类比盲人下山：每步沿梯度负方向（最陡
   下降方向）走一步，逐步逼近最低点。更新：θ := θ - α·∇J(θ)。α 为学习率——
   太小收敛慢，太大可能跳过最小值（overshoot）。

4. 逻辑回归
   用于二分类的方法。在线性回归基础上套 Sigmoid 函数，输出压缩到 (0,1)，表示
   属于正类的概率。虽叫"回归"实为分类。代价函数用交叉熵（而非平方损失），因为
   后者会导致非凸优化。决策边界：θ^T·x = 0 时概率为 0.5。

5. Sigmoid 函数
   σ(z) = 1/(1+e^(-z))，输出范围 (0,1)。关键性质：导数 σ'(z) = σ(z)(1-σ(z))，
   便于梯度计算；对称性 1-σ(z) = σ(-z)。

6. 交叉熵代价函数
   逻辑回归使用的损失函数：J = -1/m·Σ[y_i·log(h_i) + (1-y_i)·log(1-h_i)]。
   相比平方损失：①是凸函数，保证全局最优；②自信犯错时惩罚→∞，学习更快。

7. 正则化（含 L1/L2）
   防止过拟合的技术，在损失函数上叠加模型复杂度惩罚项：J_new = Loss + λ·R(w)。
   L1 正则化（Lasso）：R(w)=Σ|w_j|，产生稀疏解（参数精确为 0），有特征选择功
   能，0 点不可导。
   L2 正则化（Ridge）：R(w)=Σw_j²，所有参数均匀缩小但不为零，处处可导。
   λ 大→强正则化，可能欠拟合；λ 小→弱正则化，可能过拟合。


二、简答题（5道）
---------------------------------------------------------------------------

Q1：回归与分类的区别？
    回归预测连续数值，输出实数；分类预测离散类别，输出标签或概率。线性回归是
    回归，逻辑回归虽叫回归实为分类。

Q2：梯度下降的原理是什么？
    类比盲人下山——当前位置→沿负梯度方向迈步→重复直到山谷。步骤：(1)确定学
    习率α；(2)初始化参数；(3)同步更新所有参数 θ := θ - α·∇J(θ)；(4)下降幅度
    小于阈值时停止。线性回归的代价函数是凸函数，梯度下降必找到全局最优。

Q3：为什么逻辑回归不能用平方损失？
    Sigmoid 是非线性的，(h-y)² 叠加后代价函数变成非凸函数，有多个局部最小值，
    梯度下降不可靠。交叉熵是凸函数，保证收敛到全局最优。

Q4：过拟合的原因及解决方法？
    原因：模型太复杂、训练数据太少或噪声多。解决方案：正则化（L1/L2）约束参数
    大小；增加训练数据；降低模型复杂度；早停（Early Stopping）。

Q5：L1 正则化和 L2 正则化的区别？
    L1（Lasso）：正则项 Σ|w_j|，产生稀疏解（参数精确为零），自动特征选择，0点
    不可导需坐标下降等特殊算法。
    L2（Ridge）：正则项 Σw_j²，参数非稀疏（均匀缩小但不为零），处处可导，可用
    标准梯度下降。模型更稳定但所有特征都参与。

第三章 线性分类器
================================================================================

一、名词解释（3个）
---------------------------------------------------------------------------

1. 线性判别函数
   形式 g(x) = w^T·x + w₀。w 为权矢量（决策面的法向量，指向正侧），w₀ 为偏置
   （决定决策面到原点的距离）。几何意义：g(x) = r·||w||，正比于点 x 到决策面
   的有向距离。决策规则：g(x)>0 判为 C₁ 类，g(x)<0 判为 C₂ 类。也可写为增广
   形式：x=(1,x₁,...,x_d)^T, w=(w₀,w₁,...,w_d)^T，此时 g(x) = w^T·x。

2. 线性可分
   若存在一个权向量 w，使所有 ω₁ 类样本满足 w^T·y>0，ω₂ 类样本满足 w^T·y<0，
   则称该样本集线性可分。此时必然存在至少一个线性分类器能正确分类所有样本。

3. 分类
   监督学习任务，预测目标是离散类别标签（如是/否、猫/狗）。与回归不同：回归
   输出连续数值，分类输出类别或概率。

二、简答题（4道）
---------------------------------------------------------------------------

Q1：线性判别函数的几何意义？
   权矢量 w 是决策面的法向量，方向指正侧(C₁ 类)。判别函数值 g(x) 正比于点 x
   到决策面的有向距离：g(x) = r·||w||。偏置 w₀ 决定决策面与原点距离 r₀ =
   w₀/||w||。分类就是用超平面将特征空间分成两个半空间。

Q2：多分类的三种拆分策略及对比？
   一对其余 (OvR)：m 类需 m 个分类器，每类 vs 其余类。优点是简单直接、分类
   器数量少；缺点是存在不确定区域（多个分类器同时判正或全判负），且每类训练
   时正负样本数严重不平衡，影响分类器性能。
   一对一 (OvO)：m 类需 m(m-1)/2 个分类器，两两类别配对训练。优点是每个分
   类器只涉及两类，更容易线性可分，不受类别不平衡影响；缺点是分类器数量随
   m 二次增长，预测时需全部运行一遍再投票，开销大。同样存在不确定区域（投票
   平局时）。
   多对多 (MvM)：m 个判别函数 d_i(x)，决策规则为最大值判别 d_i(x) > d_j(x)
   (j≠i)。优点是分类器数与 OvR 相同（m 个），但无不确定区域，是处理多分类问
   题最常用的方案。本质上是用 m 个线性函数形成 m(m-1)/2 个决策面 d_i = d_j。
   注意：课件中的 MvM 似乎和标准定义有所差别。

Q3：分类和聚类的区别？
   分类：监督学习，训练数据有标签，目标是学习决策边界将新样本分到已知类别。
   聚类：无监督学习，训练数据无标签，目标是发现数据内在结构，将相似样本归到
   同一簇。分类需要标注数据，聚类不需要。

Q4：特征工程包含哪些主要操作？特征选择与特征提取的区别？
   特征工程主要包括：特征构造（组合/变换原始特征）、特征选择、特征提取。
   特征选择：从原始特征中选出最相关的子集，不创建新特征，保留物理含义。
   特征提取：通过数学变换（如 PCA）将原始特征映射到新空间，创建新特征，可能
   丢失原始物理含义，但降维效果更强。

第四章 支持向量机
================================================================================

一、名词解释（4个）
---------------------------------------------------------------------------

1. 支持向量机（SVM）
   寻找最大间隔超平面的二分类方法。核心思想：找到训练集中边缘上的若干数据（支
   持向量），用这些点找出一个超平面，使支持向量到平面的间隔（margin）最大。
   间隔 = 2/||w||，最大间隔意味着最好泛化能力。相比逻辑回归，SVM 在处理复杂
   非线性问题时更清晰有效。

2. 支持向量
   训练样本中距离最优超平面最近的那些点，满足 y_i(w·x_i+b) = 1（落在间隔边界
   上）。SVM 的解只由支持向量决定——其他样本的拉格朗日乘子 α_i = 0，不参与决
   策函数。这也是 SVM 稀疏性和泛化能力强的根本原因。

3. 核函数
   ★ 核函数的作用是将样本从原始空间映射到更高维的特征空间，使原来线性不可分
   的数据在高维空间中变得线性可分。定义：K(x,z) = φ(x)·φ(z)，直接在原始空间
   计算高维内积，无需显式计算映射 φ（核技巧）。常见核函数：线性核 K(x,z)=
   x·z（等价于原 SVM）；多项式核 K(x,z)=(x·z+1)^d；高斯核/RBF K(x,z)=
   exp(-||x-z||^2/2σ^2)（最常用，映射到无限维）。

4. 软间隔与硬间隔
   硬间隔：要求所有样本完全正确分类，不允许任何错误，约束 y_i(w·x_i+b) ≥ 1。
   仅适用于线性可分数据。
   软间隔：引入松弛变量 ξ_i ≥ 0，放宽约束为 y_i(w·x_i+b) ≥ 1-ξ_i，允许少量误
   分类。目标函数 min 1/2·||w||^2 + C·Σξ_i。惩罚参数 C 大→趋向硬间隔，可能过
   拟合；C 小→允许更多错误，间隔更宽。


二、简答题（3道）
---------------------------------------------------------------------------

Q1：SVM 的核心思想和优化目标？
    找到使间隔最大的超平面。最大化间隔等价于最小化 ||w||：min 1/2·||w||²，
    s.t. y_i(w·x_i+b) ≥ 1。通过拉格朗日乘数法转为对偶问题求解，最终判别函数
    f(x) = Σα_i·y_i·(x_i·x) + b，仅支持向量对应的 α_i > 0。

Q2：软间隔 SVM 与硬间隔 SVM 的区别？
    硬间隔：要求所有样本完全正确分类，y_i(w·x_i+b) ≥ 1 对所有样本严格成立，
    仅适用于线性可分数据。
    软间隔：引入松弛变量 ξ_i，放宽约束为 y_i(w·x_i+b) ≥ 1-ξ_i，允许部分样本
    被错分。目标函数增加惩罚项 C·Σξ_i。C 大→接近硬间隔（偏差小、方差大）；
    C 小→间隔宽、容错高（偏差大、方差小）。

Q3：核函数的作用是什么？常见类型有哪些？
    ★ 将低维线性不可分的数据映射到高维特征空间，使其线性可分。通过核技巧直接
    计算 K(x,z)=φ(x)·φ(z)，避免显式映射的计算开销。常见类型：
    线性核：K(x,z) = x·z；多项式核：K(x,z) = (x·z+1)^d；
    高斯核/RBF：K(x,z) = exp(-||x-z||^2/2σ^2)，映射到无限维，最常用。

第五章 聚类算法
================================================================================

一、名词解释（3个）
---------------------------------------------------------------------------

1. 聚类
   无监督学习方法，训练数据没有标签，目标是将相似的数据分配到同一个簇，使簇
   内相似度高、簇间相似度低。与分类（监督学习，有标签、学决策边界）本质不同。
   应用：医疗诊断、搜索引擎、客户分群。

2. K-means（K-均值聚类）
   最常用的聚类算法。将数据分成 K 个预定义的不重叠的簇，迭代优化使簇内点到质
   心（簇内均值）的平方距离之和最小。
   流程：(1)随机选 K 个初始质心；(2)每个点分配到最近质心的簇；(3)重新计算每
   簇的均值作为新质心；(4)重复(2)(3)直到质心不再变化或达到最大迭代次数。
   缺点：需预指定 K；对初始值和异常值敏感；不适合非球形簇。

3. 数据标准化
   数据预处理技术，消除不同属性量纲差异（如 0.1 vs 720），使各属性在距离计算
   中贡献均等。两大方法：
   范围标准化：x' = (x-min)/(max-min)，映射到 [0,1]，对异常值敏感。
   Z-score 标准化：z = (x-μ)/σ，均值为 0 标准差为 1，对异常值更鲁棒。


二、简答题（1道）
---------------------------------------------------------------------------

Q1：K-means 算法的流程和终止条件？
    流程：(1)随机选 K 个初始质心；(2)每个数据点分配到最近的质心，形成 K 个簇；
    (3)对每个簇计算所有点的均值，作为新质心；(4)重复(2)(3)直到质心不再变化或
    达到预设迭代次数。
    终止条件：质心位置不再变化（或变化小于阈值）；簇分配不再改变；达到最大迭
    代次数。

第六章 典型神经网络（CNN / RNN / 自编码器）
================================================================================

一、名词解释（5个）
---------------------------------------------------------------------------

1. 卷积神经网络（CNN）
   专为图像设计的深度学习模型，灵感源于人类视觉逐层抽象原理。核心特性：局部
   连接（神经元只连局部区域，减少连接数）和权值共享（同一卷积核在整个输入上
   共享参数，减少参数量+平移不变性）。
   架构流程：(1)输入层接收图像像素；(2)卷积层用卷积核滑动提取局部特征；(3)激
   活层（ReLU）引入非线性；(4)池化层下采样降维；(5)全连接层整合特征经Softmax
   输出分类概率。

2. 循环神经网络（RNN）
   处理序列数据的神经网络，在隐藏层增加自连接回路，将前一时刻状态 h_{t-1} 传
   递给当前时刻 h_t，使网络具有"记忆"。按时间展开可看作不同时刻共享权值的前馈
   网络。当前输出由当前输入 x_t 和历史状态 h_{t-1} 共同决定。缺点：梯度消失/
   爆炸导致难以捕捉长距离依赖。

3. 梯度消失与梯度爆炸
   深层网络反向传播时，n 个导数连乘。若导数 < 1，梯度
   指数级衰减至 0（梯度消失），前面的层无法更新；若导数 > 1，梯度指数级增长
   （梯度爆炸），训练不稳定。RNN 因时间展开多步连乘尤其严重。
   缓解方式：梯度爆炸→梯度裁剪；梯度消失→LSTM/GRU、残差连接、BatchNorm。

4. LSTM（长短期记忆网络）
   RNN 的改进变体，通过三个门控单元解决梯度消失和长期记忆问题：
   遗忘门 f：决定从长期状态 c_{t-1} 中丢弃哪些旧信息。
   输入门 i：决定哪些新信息存入长期状态 c_t。
   输出门 o：决定 c_t 中哪些信息输出为 h_t。
   每个时刻维护两个状态：长期状态 c（记忆线）和输出状态 h。

5. GRU（门控循环单元）
   LSTM 的简化版，两个门：重置门 r（控制新旧信息混合方式）和更新门 z（等价于
   LSTM 遗忘门+输入门的合并）。去掉独立输出门，直接将长期状态作为输出。参数
   更少、计算更快，效果通常与 LSTM 相当。


二、简答题（5道）
---------------------------------------------------------------------------

Q1：CNN 的卷积层和池化层分别是做什么的？
    卷积层：用卷积核（小的参数矩阵）在输入上滑动扫描，每个位置做逐元素乘法再
    求和，提取局部特征（边缘→纹理→形状）。多个卷积核提取多种特征，权值共享
    减少参数量。输出称为特征图（Feature Map）。
    池化层：对特征图进行下采样降维。最大池化取区域内最大值（保留纹理特征）；
    平均池化取区域内平均值（保留背景信息）。无学习参数，作用：减少计算量、防
    止过拟合。

Q2：激活函数 sigmoid、tanh、softmax 的定义和优缺点？
    Sigmoid：σ(z)=1/(1+e^{-z})，输出 (0,1)，适合二分类输出层。缺点：饱和区
    梯度趋零（梯度消失），输出不以 0 为中心。
    Tanh：输出 (-1,1)，以 0 为中心优于 Sigmoid。缺点：同样存在梯度饱和问题。
    Softmax：将任意分数转为概率分布 Σ=1，用于多分类输出层。缺点：计算量较大。
    非线性激活函数的作用：为网络引入非线性表达能力，否则多层线性变换等价于单
    层。

Q3：梯度消失和梯度爆炸的含义及避免方式？
    含义：见名词解释第 3 条。
    避免方式：(1)使用 ReLU 等非饱和激活函数替代 sigmoid/tanh；(2)梯度裁剪（限
    制梯度最大范数）；(3)使用 LSTM/GRU 替代基础 RNN；(4)残差连接（ResNet）；
    (5)Batch Normalization；(6)合适的权重初始化。

Q4：深度自编码器的架构组成？
    由编码器和解码器组成。编码器将高维输入逐层压缩为低维隐变量（Code），解码
    器从 Code 逐层重构回原始输入。训练目标：最小化输出与输入的重构误差。应用：
    数据降维与特征抽取、文本/图像检索（基于 Code 相似度）、预训练网络初始化。

Q5：LSTM 和 GRU 的基本组件及区别？
    LSTM：三个门——遗忘门(丢弃旧信息)、输入门(存入新信息)、输出门(控制输出)。
    两个状态——长期状态 c（细胞记忆）和输出状态 h。GRU：两个门——重置门 r 和
    更新门 z，融合 c 和 h 为一个状态。GRU 参数更少更快，效果通常相当。两者都
    通过门控机制有效缓解了基础 RNN 的梯度消失问题。

第七章 自监督学习
================================================================================

一、名词解释（2个）
---------------------------------------------------------------------------

1. 自监督学习（SSL）
   无监督学习的子集，利用数据本身的结构自动构造监督信号——将数据一部分作为输
   入，另一部分作为预测目标（伪标签），不依赖外部人工标注。是 BERT（掩码语言
   模型）和 GPT（下一词预测）的基石。意义：突破标注瓶颈，利用海量无标注数据。

2. BERT
   基于 Transformer 编码器的自监督预训练模型。双向注意力（能同时看到上下文），
   输入 N 词→输出 N 个向量。通过两个预训练任务在海量无标签数据上学习：掩码
   语言模型（MLM，完形填空）和下一句预测（NSP，判断两句是否相邻）。预训练后
   通过微调（Fine-tuning）适配下游任务——同一模型只需加不同输出层即可处理情感
   分析、问答、词性标注等任务。特点是语境化嵌入：同一词在不同上下文中产生不
   同向量，自然消除一词多义。

第八章 注意力机制与Transformer
================================================================================

一、名词解释（3个）
---------------------------------------------------------------------------

1. 自注意力机制（Self-Attention）
   输入序列 X 分别乘以 W_Q、W_K、W_V 得到 Query(Q)、Key(K)、Value(V) 三组
   向量。输出 = Softmax(QK^T/√d_k)·V，即 V 的加权和，权重由 Q-K 相关性决定。
   核心优势：一次矩阵乘法即可直接建模序列中任意两位置间的依赖（非局部依赖），
   无需 CNN/RNN 的层层传递。

2. Transformer
   完全基于注意力机制的 Seq2Seq 架构。采用编码器-解码器（Encoder-Decoder）
   结构：编码器将输入序列编码为中间表示，解码器从中自回归生成输出序列。核心
   组件：多头自注意力、位置编码、前馈网络、残差连接+层归一化。位置编码用正
   弦/余弦函数为序列注入顺序信息（因为自注意力本身不含位置感知）。最大优势：
   高度并行化（无 RNN 串行瓶颈）、直接建模任意距离依赖。

3. 多头注意力（Multi-Head Attention）
   自注意力的扩展——输入映射到 h 组不同的 Q/K/V，每组独立计算注意力（每个
   "头"在不同子空间学习不同特征），最后拼接所有头的输出做线性变换。优点：并行
   捕捉多种类型的相关性（如语法、语义），增强模型表达能力。


二、简答题（4道）
---------------------------------------------------------------------------

Q1：Transformer 中 Q、K、V 分别是什么含义？
    Q（Query）：当前要查询的目标位置的表示，相当于"我要找什么"。
    K（Key）：所有位置的"标签"，用于与 Q 计算相关性（匹配程度）。
    V（Value）：所有位置的实际信息内容。
    计算过程：Q 与每个 K 做点积得到相似度分数，Softmax 归一化后作为权重，对
    V 加权求和得到输出。除以 √d_k 是为了防止点积值过大导致 Softmax 梯度消失。
    ★ 位置编码：自注意力不含位置感知，需额外注入位置编码（正弦/余弦函数）使
    模型区分词的先后顺序。否则"我爱你"和"你爱我"的表示完全相同。

Q2：简述 BERT 的预训练任务，重点说明 MLM 的原理与目的？
    BERT 有两个预训练任务：
    掩码语言模型（MLM）：随机遮盖 15% 的词元，让模型根据双向上下文预测被遮盖
    的原始词。本质是"完形填空"。目的：强制模型利用上下文深层语义来预测，从而
    学到词语的双向语义表示——不能"偷看"自身。
    下一句预测（NSP）：给定句子 A 和 B，判断 B 是否为 A 的下一句（二分类）。
    目的：学习句子间的逻辑关系，为推理和问答任务打下基础。

Q3：BERT 和 GPT 的核心区别？
    BERT：基于 Transformer 编码器，双向注意力（同时看上、下文），训练任务是
    完形填空（MLM），擅长语言理解（分类、抽取、推理）。
    GPT：基于 Transformer 解码器，单向/因果注意力（只能看过去），训练任务是
    预测下一个词，擅长语言生成与创作。
    简单记：BERT 是"理解者"（看整句话填空），GPT 是"创造者"（看上文续写）。

================================================================================
第九章 迁移学习
================================================================================

一、名词解释（3个）
---------------------------------------------------------------------------

1. 迁移学习
   将从一个或多个源任务中学到的知识和模式，应用到不同但相关的目标任务上，以
   提升目标任务的性能。核心条件：源域 ≠ 目标域，或源任务 ≠ 目标任务。与传
   统 ML 不同——迁移学习不需要训练和测试数据同分布，可复用已有模型，目标域标
   注数据可以很少。

2. 领域自适应（Domain Adaptation, DA）
   训练时能够接触到目标域数据（虽然无标签），利用源域有标签 + 目标域无标签数
   据，使模型在目标域上表现良好。方法如领域对抗训练（DANN）：特征提取器尽量
   让域分类器分不清数据来自哪，同时保证标签分类器正确，学到与领域无关的通用
   特征。

3. 领域泛化（Domain Generalization, DG）
   训练时完全无法接触目标域数据（盲考），要求模型在未知目标域上仍保持泛化能
   力。训练数据来自一个或多个源域，测试数据来自未见过的目标域。方法：数据增
   强（增加多样性）、表征学习（提取领域不变特征）、元学习/集成学习。


二、简答题（3道）
---------------------------------------------------------------------------

Q1：领域自适应(DA)与领域泛化(DG)的区别？
    DA 训练时能见到目标域数据（无标签），相当于"知道考什么题型但没答案"；
    DG 训练时完全见不到目标域数据，相当于"盲考"。
    核心差异：DA 可以利用目标域的分布信息进行特征对齐；DG 只能从源域中学习
    通用的、可迁移的知识，难度更大。

Q2：Fine-tuning（微调）的策略选择原则是什么？
    ★ 两阶段：先在大型源域数据上预训练，再用目标域小数据微调。
    保守训练：加入正则化约束，防止目标模型参数偏离源模型太远，避免在小样本上
    过拟合或灾难性遗忘。
    层迁移策略：数据很少→冻结底层（底层特征是通用的，只微调顶层）；数据充足
    →微调全层。图像任务通常迁移前几层（边缘检测等底层特征通用），语音任务通
    常迁移后几层。

Q3：没有目标域样本的情况下如何做迁移？
    即零样本学习（Zero-shot Learning）或领域泛化（DG）。
    零样本学习：建立"视觉空间→语义空间"的映射，让模型学会辨认通用属性（如有
    毛发、四条腿）而非死记类别。推理时：新样本映射到语义空间→找最近类原型→
    输出类别。例如从没见过"斑马"，但识别出"条纹+马形"就能推理。

================================================================================
第十章 强化学习
================================================================================

一、名词解释（4个）
---------------------------------------------------------------------------

1. 强化学习（RL）
   智能体（Agent）与环境交互，根据奖励信号调整策略，以最大化长期累积奖励（期
   望回报）。核心要素：状态 S（当前局面）、动作 A（可选行为）、奖励 R（即时反
   馈）、策略 π(a|s)（选动作的概率分布）、状态转移 P(s'|s,a)（执行动作后环
   境的变化）。回报 U_t = r_t + γ·r_{t+1} + γ²·r_{t+2} + ...，折扣率 γ 控制
   未来奖励的权重（γ≈0 短视，γ≈1 远见）。与监督学习不同：RL 的监督信号来自
   环境的延迟奖励，而非人工标注。

2. 策略（Policy）π(a|s)
   智能体在状态 s 下选择动作 a 的概率分布。是 RL 的核心学习对象——目标就是找到
   最优策略最大化期望回报。通常用神经网络（策略网络）近似，输出各动作概率并经
   Softmax 归一化。

3. 动作价值函数（Q 函数 / Q-learning）
   Q_π(s,a) = E[U_t | S_t=s, A_t=a]，给定策略 π，在状态 s 采取动作 a 后期望
   获得的回报。用于评估"在 s 下选 a 有多好"。最优 Q 函数 Q*(s,a) = max_π Q_π，
   有了 Q* 即可选最优动作 a* = argmax Q*(s,a)。
   DQN：用神经网络 Q(s,a;w) 近似 Q*，通过 TD 学习更新。TD 目标 y_t = r_t +
   γ·max_a Q(s_{t+1},a;w)，最小化 (Q - y)² 迭代优化。
   V(s) 是 Q 关于动作的期望：V(s) = Σ_a π(a|s)·Q(s,a)，评估状态本身好坏。

4. Actor-Critic 方法
   结合基于价值（Value）和基于策略（Policy）的方法。
   Actor（策略网络）：负责决策——根据状态选动作。用策略梯度更新：好动作（Q值
   高）增大概率，坏动作（Q值低）减小概率。
   Critic（价值网络）：负责评价——评估 Actor 动作的好坏（输出 Q 值）。用 TD 学
   习更新，最小化预测与实际的差距。
   训练时两者协作（Critic 是教练，Actor 是运动员），测试时只用 Actor。


二、简答题（3道）
---------------------------------------------------------------------------

Q1：强化学习中智能体与环境交互的核心要素有哪些？
    状态 S：描述当前环境局面（如游戏截图、棋盘）。
    动作 A：智能体可选的行为（如左/右/上、下棋位置）。
    奖励 R：环境对动作的即时反馈（+1 得分，-1 失败，0 无事发生）。
    策略 π：给定状态选动作的概率分布，RL 的学习目标。
    状态转移 P(s'|s,a)：执行动作后环境变化到新状态的概率（可能随机）。
    交互流程：观察状态 S_t → 根据策略选动作 A_t → 环境返回奖励 R_t 和新状态
    S_{t+1} → 重复。

Q2：基于价值的方法（DQN）与基于策略的方法（Policy Gradient）的区别？
    基于价值（DQN）：学习 Q 函数，间接选动作（argmax Q）。适合离散动作空间。
    缺点：无法处理连续动作和随机策略。
    基于策略（Policy Gradient）：直接学习策略函数 π(a|s)，输出动作概率分布，
    通过梯度上升最大化期望回报。适合连续动作和随机策略。缺点：收敛可能不稳定、
    局部最优。
    Actor-Critic 结合两者：Critic 学 Q 提供评分，Actor 学 π 做决策。

Q3：Actor-Critic 中 Actor 和 Critic 各自的职责？
    Actor（策略网络）：接收状态，输出动作概率分布，随机采样执行动作。用策略
    梯度更新 θ ← θ + β·Q(s,a)·∇log π(a|s;θ)，增加高 Q 值动作的概率。
    Critic（价值网络）：接收状态和动作，输出该动作的 Q 值。用 TD 学习更新
    w ← w - α·(Q(s,a;w) - (r + γ·Q(s',a';w)))·∇Q。
    训练后只用 Actor 做决策，Critic 退役。

Q4：推导回报递推恒等式 U_t = r_t + γ·U_{t+1}
    折扣回报定义：U_t = r_t + γ·r_{t+1} + γ²·r_{t+2} + γ³·r_{t+3} + ...
    t+1时刻回报：U_{t+1} = r_{t+1} + γ·r_{t+2} + γ²·r_{t+3} + ...
    将U_{t+1}两边乘以γ：γ·U_{t+1} = γ·r_{t+1} + γ²·r_{t+2} + γ³·r_{t+3} + ...
    对比U_t定义：U_t = r_t + (γ·r_{t+1} + γ²·r_{t+2} + γ³·r_{t+3} + ...)
    括号内恰好是γ·U_{t+1}，即 U_t = r_t + γ·U_{t+1}。得证。
    意义：当前时刻的总回报 = 当前即时奖励 + 折扣后的未来总回报。

Q5：推导最优动作价值函数 Q*(s,a)
    动作价值函数：Q_π(s_t,a_t) = E[U_t | S_t=s_t, A_t=a_t]
    即给定策略π，在状态s采取动作a后所能获得的期望总回报。
    最优Q函数：Q*(s_t,a_t) = max_π Q_π(s_t,a_t)
    无论用什么策略，在(s,a)下的期望回报都不会超过Q*。
    有了Q*就能得到最优动作：a* = argmax_a Q*(s,a)
    DQN思路：用神经网络Q(s,a;w)近似Q*(s,a)，通过TD学习迭代更新w。

Q6：推导TD学习的更新公式
    (1) 由回报恒等式U_t = r_t + γ·U_{t+1}，用Q函数代替回报（DQN使用Q-learning形式）：
        Q(s_t,a_t;w) ≈ r_t + γ·max_a Q(s_{t+1},a;w)
        左端是当前预测值，右端y_t = r_t + γ·max_a Q(s_{t+1},a;w)即为TD目标
    (2) TD误差：δ_t = Q(s_t,a_t;w) - (r_t + γ·Q(s_{t+1},a_{t+1};w))
        误差越小，Q函数越接近真实值。
    (3) 损失函数：L = 1/2 * (Q(s_t,a_t;w) - y_t)^2
    (4) 求梯度：dL/dw = (Q - y) * dQ/dw = δ_t * dQ/dw
    (5) 梯度下降更新：w ← w - α * δ_t * dQ/dw
    α为学习率。这个更新公式是DQN和Actor-Critic中Critic的训练核心。

第十一章 扩散学习
================================================================================

一、名词解释（3个）
---------------------------------------------------------------------------

1. 生成模型
   一类学习数据真实分布 P(x) 的算法，能够生成与真实数据相似的新数据。形式化：
   训练模型 P_θ(x) 逼近真实分布 P_r(x)。主流模型包括 GAN、VAE、扩散模型。应
   用：文生图、语音合成、视频生成、3D 生成。

2. GAN（生成对抗网络）
   由生成器 G 和判别器 D 两个网络组成。生成器：接收随机噪声，产生"伪图像"试
   图以假乱真。判别器：输入图像（真或伪），判断真伪（输出 0~1 概率）。类比：
   伪造者(G) 和 警察(D) 在对抗中各自进步。目标函数：min_G max_D E[log D(x)]
   + E[log(1-D(G(z)))]。优点：生成快、图像逼真。缺点：训练难、易模式崩溃。

3. 扩散模型（DDPM）
   基于扩散过程的生成模型，Stable Diffusion 的底层原理。两阶段：
   正向扩散（加噪）：向真实图像逐步添加高斯噪声，T 步后变成纯噪声——马尔可夫
   过程，每步 x_t = √(1-β_t)·x_{t-1} + √β_t·ε。
   反向去噪（生成）：训练神经网络（通常 UNet）预测每步加入的噪声，从纯噪声逐
   步去噪还原出逼真图像。损失 L ∝ ||ε - ε_θ(x_t,t)||²，即让模型预测出之前加
   入的噪声。优点：生成质量最高。缺点：采样慢（需逐步去噪）。


二、简答题（2道）
---------------------------------------------------------------------------

Q1：GAN 中生成器和判别器的区别？
    生成器 G：输入随机噪声 z，生成假图像 G(z)，目标是骗过判别器（让 D(G(z))
    尽量接近 1）。损失 min_G E[log(1-D(G(z)))]。
    判别器 D：输入真实图像 x 或生成图像 G(z)，判断真伪（真→1，假→0）。损失
    max_D E[log D(x)] + E[log(1-D(G(z)))]。
    两者交替训练、相互对抗，最终 G 生成的图像足以以假乱真。

Q2：扩散模型中前向扩散过程和反向去噪过程的区别？
    正向扩散（x_0 → x_T）：逐步向图像添加高斯噪声，每次加噪比例 β_t 递增，T
    步后图像变为纯噪声 N(0,I)。这是一个固定的随机过程，不需要学习。
    反向去噪（x_T → x_0）：训练神经网络 ε_θ(x_t,t) 预测每一步加入的噪声，然
    后从噪声图中减去预测噪声得到上一步图像。这是需要学习的生成过程，核心是让
    模型学会去噪。

强化学习 番外 — 后训练与 RLHF
================================================================================

一、名词解释（3个）
---------------------------------------------------------------------------

1. 大模型后训练三阶段
   预训练：海量无标注文本，学习通用语言能力（周期最长）。
   监督微调（SFT）：用人工标注的问答对微调，增强指令遵循能力。本质是行为克隆
   ——模仿人类的回答方式。
   对齐训练（RLHF/RLVR）：用强化学习使模型对齐人类偏好和价值观——不仅要答对，
   还要安全、友好、遵循伦理。

2. RLHF（基于人类反馈的强化学习）
   ★ 三步：(1)SFT——人工标注问答对监督微调；(2)训练奖励模型——让模型生成多个
   回答，人类排序，训练 RM 学习打分；(3)PPO/GRPO 强化学习——用 RM 对输出打分，
   优化策略模型。解决了"模型输出质量高不等于人类满意"的问题。

3. RLVR（基于可验证奖励的强化学习）
   ★ 用客观验证规则替代 RLHF 中的人类偏好奖励模型。适用于有明确对/错标准的任
   务（数学证明、代码正确性）：输出正确=1，错误=0。优势：不含人类主观偏见、
   不需要昂贵标注、模型可能超越人类水平。劣势：不适用主观任务（写作好坏）。


二、简答题（1道）
---------------------------------------------------------------------------

Q1：从数据安全角度，为什么商业公司要自己搭建本地模型？
    1. 数据不外传：使用云端 API 意味着将内部数据发送给第三方，涉
    及商业机密、客户隐私、合规风险（如 GDPR）。
    2. 模型可控：本地部署可自行控制模型的训练数据、输出行为和安全策略，避免外
    部模型更新导致不可预期的行为变化。
    3. 领域定制：可在内部数据上微调，使模型适配公司特定业务场景（如法律、医疗、
    金融），效果优于通用模型。
    4. 成本与可靠性：大规模使用时本地部署的边际成本更低，且不依赖外部网络和服
    务可用性。

大语言模型关键技术
================================================================================

一、名词解释（3个）
---------------------------------------------------------------------------

1. 大语言模型（LLM）
   基于 Transformer 的超大规模预训练语言模型，在海量文本（数千亿字符）上训练，
   参数量数十亿到万亿级。核心理念：通过语言生成统一所有可用语言完成的任务——
   写作、翻译、编程、推理等。代表：GPT 系列、ChatGPT、DeepSeek。

2. 情境学习（In-Context Learning, ICL，语境学习）
   ★ 无需更新模型参数，通过在 Prompt 中提供任务描述和少量范例，模型即能理解
   任务并生成答案。三种方式：Few-shot（给几个范例）、One-shot（给一个范例）、
   Zero-shot（只给任务指令不给范例）。GPT-3 首次大规模验证：模型越大，ICL 效
   果越好。

3. 思维链（Chain-of-Thought, CoT）
   在 Prompt 的示例中展示逐步推理过程（而非直接给答案），引导模型在输出前先生
   成中间推理步骤。能显著提升复杂推理任务（数学、逻辑）的准确率。衍生：CoT-SC
   （多路径投票）、ToT（思维树搜索）。


二、简答题（1道）
---------------------------------------------------------------------------

Q1：语境学习（ICL）的主要学习范式有哪些？
    Few-shot（小样本）：给模型几个问答范例 + 新问题，模型参照范例格式回答。
    One-shot（单样本）：只给一个范例。
    Zero-shot（零样本）：完全不给范例，只描述任务（如"将以下文本翻译成法语"），
    测试模型是否真正"理解"了指令。模型规模越大效果越好，GPT-3 在 175B 参数时
    涌现出强大的 Zero-shot 能力。
